# Google Homepage Clone

A simple recreation of Google's homepage built using **HTML and CSS**. This project helped me practice the fundamentals of frontend web development by recreating Google's familiar layout and design.

## Features

- Google's colorful logo
- Navigation links for Gmail, Images, About, and Store
- Search bar with rounded corners and hover effects
- Google Search and I'm Feeling Lucky buttons
- Footer with additional links
- Responsive layout for smaller screens

## Tech Stack

- **HTML5** — webpage structure
- **CSS3** — styling, layout, and hover effects

## Project Structure

```text
google-homepage/
├── index.html
├── styles.css
└── README.md
```

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/pasta-07/google-homepage-clone.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
